———guide to the nomenclature and directory structures used in this project——— 

files in filt/dat/struct/[pdb, binding-sites, filtered-binding-sites] are sorted into sub-directories
by their PDB ID's middle 2 characters.
eg. pdbxaby.ent would be found at filt/dat/struct/pdb/ab/pdbxaby.ent

binding site (filt/dat/struct/(filtered-)binding-sites/ab/):
pdbxaby_C_****_Lig.pdb
eg pdb1g29_A_0377_NA.pdb
when splitting by underscore:
token 0: pdb id, token 1: chain id, token 2: ligand number, token 3: ligand name

pdb file (filt/dat/struct/pdb/ab/):
pdbxaby.ent
eg pdb1avn.ent

cluster entry (filt/dat/clusters-by-entity-70.txt):
XABY_N

XABY/xaby = PDB ID (upper/lower-case), C = chain identifier, **** = residue sequence number,
Lig = ligand name (abbreviated) [1-3 chars], ab = middle two characters of the PDB ID,
N = molecular entity number
